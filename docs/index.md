# 我的文档实践站

这个站点是《软件工程概论》第二次实践作业的成果：四页 Markdown 由 MkDocs 和 Material 主题生成静态页面，推送到仓库后由 GitHub Actions 完成构建和发布，最终托管在 GitHub Pages 上。

## 基本信息

| 项目 | 内容 |
| --- | --- |
| GitHub | shizi-shizi |
| 署名 | yuanshiwen |
| 专业 | 软件工程 |
| 主题 | 静态文档的构建与自动部署 |

## 通过这次实践掌握的

1. 用 Markdown 编写四页内容，在 `mkdocs.yml` 中统一站点名称、主题和导航。
2. 在本地完成构建与预览，用 `--strict` 在推送前发现链接等配置问题。
3. 配置 GitHub Actions 工作流，让构建和发布随推送自动完成，不再手工上传文件。
